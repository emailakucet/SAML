Cara Hoskan di GitHub Pages & Install Terus di Telefon Android

Aplikasi ini telah terbina dengan Web App Manifest (ikon 192x192 & 512x512) & Service Worker sokongan luar talian.

  1. 1. Muat Naik ke GitHub Pages

    Cipta repositori di github.com (cth: qm-amto-16skn), muat naik fail ini sebagai index.html, dan aktifkan Settings > Pages > Branch: main.

  2. 2. Buka di Google Chrome Android

    Buka pautan https://<username>.github.io/qm-amto-16skn/ menggunakan pelayar Google Chrome pada telefon Android anda.

  3. 3. Klik "Install App / Add to Home Screen"

    Tekan butang Install Android App di bahagian atas aplikasi (atau menu Chrome ⋮ > Add to Home screen / Install app). Ikon QM B200T akan muncul seperti aplikasi Android sebenar!

Panduan Install Aplikasi di Android (PWA)

Nota Penting Android: Sistem keselamatan Android Chrome memerlukan aplikasi dibuka melalui pautan HTTPS (seperti GitHub Pages) untuk memaparkan ikon Install App secara automatik pada Home Screen.

Langkah A — Muat Naik ke GitHub Pages:

  • Simpan fail ini sebagai index.html (atau klik Simpan HTML Data jika anda sudah kemas kini data).
  • Muat naik ke repositori GitHub anda dan aktifkan Settings > Pages > Branch: main.

Langkah B — Pasang Pada Telefon Android:

  • Buka pautan GitHub Pages tersebut menggunakan Google Chrome di Android.
  • Tekan butang Install Android App di bawah, ATAU tekan ikon tiga titik (⋮) di penjuru kanan atas Chrome > pilih Add to Home screen / Install app.
  • Aplikasi akan dipasang dengan mod skrin penuh (Standalone) tanpa bar alamat pelayar.

Reset Semua Data Ke Nilai Asal?

Semua perubahan pada checklist, staf, CAR/5-Whys, kalendar, dan pautan akan dikembalikan kepada data asal. Pastikan anda telah membuat Export JSON jika ingin menyimpan perubahan semasa.
